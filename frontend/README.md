# Frontend de SmartTraining

SPA React/TypeScript creada con Vite y Tailwind CSS. En desarrollo consume `/api` mediante el proxy de Vite, por lo que funciona aunque Vite elija 5174 u otro puerto local. Use `VITE_API_URL` sólo cuando frontend y API se publiquen por separado.

```powershell
npm install
npm run dev
```
