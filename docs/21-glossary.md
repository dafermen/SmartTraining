# Glosario

- **API REST:** interfaz HTTP organizada alrededor de recursos.
- **Bcrypt:** función adaptativa para hash de contraseñas.
- **Controlador:** adaptador entre HTTP y servicio.
- **FFmpeg/ffprobe:** herramientas para procesar y analizar medios.
- **HTTP Range:** solicitud de una porción de bytes de un recurso.
- **JWT:** token firmado con identidad y expiración.
- **Middleware:** función que procesa una petición antes/después del controlador.
- **Repositorio:** abstracción de persistencia.
- **Servicio:** reglas y casos de uso del negocio.
- **SPA:** aplicación web que navega principalmente en el cliente.
- **Write atómico:** reemplazo donde lectores ven la versión anterior o nueva, no una parcial.
