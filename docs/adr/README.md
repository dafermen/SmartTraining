# Registros de decisiones de arquitectura

Los ADR documentan decisiones de largo plazo y sus consecuencias.

## Estados

- `Proposed`
- `Accepted`
- `Superseded`
- `Deprecated`

## Convención

Use `NNNN-titulo.md`, copie `template.md` y no reescriba una decisión aceptada para ocultar su historia. Cree un ADR nuevo que indique cuál reemplaza.
