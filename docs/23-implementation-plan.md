# Plan de implementación

## Orden

1. **Fases 0–1:** definición, contratos, arquitectura, riesgos y tablero (esta entrega).
2. **Fase 2:** Vite/React y Express/TypeScript mínimos, configuración, lint, pruebas smoke, seed.
3. **Fase 3:** autenticación vertical completa de JSON a rutas/UI.
4. **Fase 4:** jerarquía de capacitaciones y administración.
5. **Fase 5:** carga y ciclo `PROCESSING → READY/ERROR`, luego streaming.
6. **Fase 6:** catálogo/reproductor/progreso.
7. **Fase 7:** lector Markdown y completar manuales con capturas.
8. **Fase 8:** ampliar matriz de riesgos/pruebas y responsive.
9. **Fase 9:** revisión, demo, despliegue y release.

## Estrategia

Cada fase entrega cortes verticales pequeños. Antes de cerrar: actualizar documentos y tablero, ejecutar formato/lint/tipos/pruebas/build aplicables, realizar prueba manual y registrar limitaciones. Los cambios de seguridad reciben pruebas negativas.

## Próxima iteración (cierre de Fases 7–8)

- Incorporar capturas finales de los recorridos ADMIN y LEARNER.
- Validar enlaces y correspondencia entre manuales e interfaz.
- Ampliar las pruebas negativas de autenticación, permisos, carga, streaming y progreso.
- Verificar responsive en móvil, tableta y escritorio.
- Ejecutar instalación limpia, lint, pruebas y build antes de preparar la entrega.
